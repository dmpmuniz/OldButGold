# CONTRIBUTING.md

> **Project:** OldButGold

## Purpose

This document defines how contributors and AI agents shall work on the project.

---

## Before Starting

Every implementation shall begin by reading:

1. DESIGN_PRINCIPLES.md
2. MASTER_SPECIFICATION.md
3. PROJECT_RULES.md

No implementation shall begin without understanding these documents.

---

## Development Philosophy

Contributors shall prefer:

* simplicity;
* deterministic behavior;
* maintainability;
* minimal code;
* minimal dependencies.

Complex solutions require technical justification.

---

## Pull Requests

Every contribution shall:

* compile successfully;
* pass acceptance tests;
* update documentation if required;
* remove obsolete code;
* preserve repository structure.

---

## Code Style

Code shall be:

* readable;
* modular;
* self-explanatory;
* deterministic.

Large functions should be divided into smaller responsibilities.

---

## AI Agent Rules

AI agents shall never:

* invent requirements;
* modify architecture;
* introduce undocumented features;
* create unnecessary files;
* duplicate existing logic.

Whenever uncertainty exists, the specification documents take precedence over assumptions.
